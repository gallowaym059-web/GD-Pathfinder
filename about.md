# AI Pathfinder

Plays the level for you by **predicting the future**.

Pathfinder clones your player into invisible shadows, simulates the next few
seconds with the game's own physics, and presses or releases the button so the
shadow survives. Clicks land on the **last tick that still works**, so
frame-perfect inputs come naturally.

- Every gamemode: cube, ship, ball, UFO, wave, robot, spider, swing
- Dual mode, gravity / speed / size portals, orbs, pads, dash orbs
- Live predicted-path overlay (like Show Trajectory)
- Everything is configured in the mod's settings, no menus

**Safe Mode** is on by default: assisted runs are marked as test runs and are
never saved or submitted.
